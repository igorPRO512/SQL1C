## Установка внешней компоненты MSSQL (OPI)

Коннектор `Ext1_OPI_MSSQL` использует внешнюю компоненту `OPI_MSSQL`
(тип AddIn, класс `Main`). Без неё `ОткрытьСоединение` не работает.

### Что нужно

- Архитектура сервера 1С и ОС совпадают с компонентой (Windows x64 или Linux x64).
- Для Linux: GLIBC >= 2.18 и OpenSSL 3.x.
- Файл компоненты `OPI_MSSQL` из релизов OpenIntegrations:
  https://github.com/Bayselonarrend/OpenIntegrations/releases/latest
  (архив компоненты для нужной платформы).

### Windows

1. Распакуйте архив компоненты в каталог, например `C:\OPI\addins\OPI_MSSQL\`.
2. В конфигураторе откройте **Администрирование → Внешние компоненты** (или
   зарегистрируйте компоненту через `regsvr32`, если она поставляется как COM-библиотека).
3. Подключите компоненту: в расширении добавьте **Общий макет** с именем `OPI_MSSQL`
   и загрузите в него zip-архив компоненты.
4. Отключите безопасный режим для расширения `1CSQLSYNCHRONYSATOR`
   (как и раньше, для COM-подключения).

### Linux

1. Распакуйте компоненту в каталог `addins` внешних компонент сервера 1С, например
   `/opt/1cv8/x86_64/<версия>/addins/`.
2. Проверьте зависимости: `ldd OPI_MSSQL.so` не должен показывать missing libraries.
3. Перезапустите сервер 1С.

### Проверка

В обработке **Настройки синхронизации SQL** нажмите **Проверить подключение**
(появится после переноса `Ext1_OPI_MSSQL`). При ошибке
`Не удалось инициализировать внешнюю компоненту` проверьте архитектуру, зависимости
и наличие макета `OPI_MSSQL`.

Имя компоненты должно оставаться `OPI_MSSQL`: модули `Ext1_OPI_*` ищут
`AddIn.OPI_MSSQL.Main`, и переименование компоненты сломает подключение.
